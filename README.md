> “圣光骑士 ➜ 糖果龙 ➜ 冰悠悠 ➜ 火鬼怪 ➜ 棉悠悠？”

最终，他用本工具成功规划出一条**超短路径**，誓要孵出属于他的：

> 🎉 **至尊·终极·超·满·配·棉悠悠** 🎉

## 🚀 使用方法

### 🔧 命令行模式
使用命令行快速查询：

```bash
python BFS.py 起始生物 目标生物
```

📌 示例：

```bash
python BFS.py 空涡龙 棉悠悠

皮皮鸡 + 雪绒狐 → 融焰娘
喵丝特 + 融焰娘 → 玉藻狐
喵丝特 + 玉藻狐 → 棉悠悠
-----------
翠叶鼠 + 空涡龙 → 吹雪狐

喵丝特 + 融焰娘 → 玉藻狐

-----------
```

```bash

```
